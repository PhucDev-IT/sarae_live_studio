# Roadmap

## Task 01 — Foundation

Desktop shell, navigation, theme, Media Library refactor, SQLite persistence, legacy migration, Web compilation, tests, and documentation.

## Task 02 candidates

1. Extract the Media Library screen into smaller reusable widgets and improve desktop keyboard access.
2. Add media file existence checks and missing-file recovery.
3. Add ffprobe metadata and thumbnail generation behind a Windows-only service.
4. Define product and presenter schemas, then add product mapping.
5. Plan the Python engine process boundary for FFmpeg and OBS.

Video editing, playlist orchestration, live control, AI replies, and cross-device synchronization remain future work.
